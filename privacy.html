Privacy Policy

Last updated: October 4, 2026

Nester Engine Publisher ("the tool") is a private application used only by its owner, on the owner's own computer, to publish the owner's videos to the owner's own YouTube channels.

YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

What data the tool accesses and how it is used

With the owner's permission, given through Google sign-in, the tool uses YouTube API Services to:

  • read the connected channel's name and ID, to show which channel is connected;
  • upload the owner's videos and set their title, description, tags, category, audience (made for kids), altered or synthetic content setting, privacy status and scheduled publish time;
  • upload each video's thumbnail;
  • post the owner's own comment on the owner's new video, only when the owner ticks "Post this comment" for that upload.

The tool does not collect or use any data about other YouTube users.

What data is stored, and where

The Google sign-in token, the connected channel's name and ID, and a history of the tool's own uploads are stored only in files on the owner's computer. The tool has no server and does not send YouTube data to anyone other than Google.

Data from YouTube other than the sign-in is kept for at most 30 days: the channel's name is refreshed from YouTube once a day while the tool runs, and each upload's YouTube video ID and messages are removed from the history after 30 days, leaving only the tool's own record (episode, title, status and publish time).

Cookies and data on devices

The tool does not use cookies, analytics or tracking. It keeps only the files described above, on the owner's computer. This website does not use cookies.

Sharing

The tool does not sell, share or transfer any data to third parties. It shows no advertisements and does not let third parties serve content.

Revoking access

Access can be removed at any time:

  • in the tool, with Disconnect, which revokes the tool's access at Google and deletes the stored sign-in from the computer; or
  • on the Google security settings page: https://security.google.com/settings/security/permissions.

Deleting data

Disconnecting a channel deletes its stored sign-in token immediately. If access is revoked on the Google security settings page instead, the tool finds this in its daily check (or when it next runs) and deletes the token. The upload history can be deleted at any time by deleting the tool's history file. Deletion requests sent to the contact address below are completed within 7 days.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy.
