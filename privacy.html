Privacy Policy

Last updated: October 4, 2026

Nester Engine Publisher ("the tool") is a private application used only by its owner, on the owner's own computer, to publish the owner's videos to the owner's own YouTube channels.

What data the tool accesses

With the owner's permission, given through Google sign-in, the tool uses YouTube API Services to upload videos and thumbnails, set video details and playlists, post comments, and read channel and video information and YouTube Analytics reports for the owner's channels.

How data is stored

The Google sign-in token, the connected channel's name and ID, and the IDs of the videos the tool uploaded are stored only on the owner's computer. The tool has no server and does not send YouTube data to anyone other than Google.

Sharing

The tool does not sell, share or transfer any data to third parties.

Revoking access

Access can be removed at any time on the Google security settings page: security.google.com/settings/security/permissions.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy. YouTube API Services are used under the YouTube Terms of Service, and the Google Privacy Policy applies.
